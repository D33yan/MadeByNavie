# MadeByNavie – Divine Nnaji Portfolio

A modern, recruiter-focused portfolio website for Divine Nnaji, showcasing frontend development, UI/UX design, and cross-platform mobile expertise. Built with Next.js, React, and Tailwind CSS, this site emphasizes accessibility, performance, and visual polish in both light and dark modes.

---

## 🚀 Features

- **Animated Hero Section:** Glassmorphism, animated gradients, SVG blobs, and a performant starry/particle background.
- **Sticky, Accessible Navigation:** Modern, responsive, and highlights the active section.
- **Skills & Tools Visualization:** Solar system animation with hover info, pause/resume, and recruiter-friendly tech stack.
- **Work/Portfolio Section:** Five professional projects with live demos, GitHub links, and modern card layout.
- **Contact Section:** Accessible, simple contact form (EmailJS integration ready).
- **Resume Download:** [Download Resume (DOCX)](./public/Divine_Nnaji_CV.docx)
- **Accessibility:** WCAG 2.1 compliance, ARIA labels, high contrast, reduced motion, and large touch targets.
- **Performance Optimized:** Animations and effects are tuned for smoothness and battery efficiency.
- **Light & Dark Modes:** Carefully crafted color palettes for both themes.

---

## 🛠️ Tech Stack

- **Framework:** Next.js (App Router)
- **Frontend:** React, TypeScript
- **Styling:** Tailwind CSS, custom CSS, Shadcn UI
- **Animation:** Framer Motion, custom React hooks
- **Forms:** EmailJS (configurable)
- **Assets:** SVG, PNG, WebP

## 📦 Getting Started

1. **Clone the repository:**
   ```bash
   git clone https://github.com/D33yan/madebynavie-portfolio.git
   cd madebynavie-portfolio
   ```
2. **Install dependencies:**
   ```bash
   npm install
   # or
   pnpm install
   ```
3. **Configure environment variables:**
   - Copy `.env.example` to `.env.local` and fill in your EmailJS credentials (see `EMAIL_SETUP.md`).
4. **Run the development server:**
   ```bash
   npm run dev
   ```
5. **Open in your browser:**
   - Visit [http://localhost:3000](http://localhost:3000)
